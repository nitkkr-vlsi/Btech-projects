# SCARA Robot Control and Automation

Arduino-based SCARA robot control project developed during a summer internship at IHFC, IIT Delhi, with Gravitaz Automation Pvt. Ltd.

## Hardware
- Arduino Uno
- Three stepper motors
- TB6600 stepper motor drivers

## Software and Tools
- Arduino C/C++
- Arduino IDE
- AccelStepper
- GeoGebra
- Wokwi

## Features
- Stepper motor control using STEP/DIR signals
- Forward and inverse kinematics
- Serial-based movement commands
- EEPROM position storage
